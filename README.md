# ORCA Marine Intelligence

A frontend-only, accessibility-first marine decision support application based on the supplied ORCA research brief. The interface is designed for fishers and coastal communities using plain language, large controls, and clear safety guidance.

## Run locally

```bash
pnpm install
pnpm dev
```

## Included screens

- Home sea briefing
- Ranked fishing zones and simple map
- Sea, weather, and tide forecast
- Safety-checked route with offline-save feedback
- Alerts, emergency confirmation, and boat checklist
- Conversational ORCA assistant
- Trip history
- Accessibility settings

The prototype uses hardcoded data and includes working navigation, zone selection, route updates, chat responses, English/Hindi/Malayalam navigation and home copy, Indian marine-source attribution, low-connectivity guidance, day/night/high-contrast themes, three text sizes, reduced motion, keyboard focus states, and responsive mobile navigation.
